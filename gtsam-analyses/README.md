# Analysis Results

This directory contains the code used to generate results and figures throughout the paper. 

# Build Instructions

Make sure that GTSAM has been built prior to building the examples in this directory. Our specific version of GTSAM (with WNOA support) can be found in the `gtsam` directory. Follow the standard build instructions for GTSAM in that directory.

These examples also make use of `yaml-cpp` provided in the `extern` directory. This library must also be built prior to building examples.

Run this snippet to build these examples:
```bash
mkdir build \
&& cd build \
&& cmake .. \
&& make -j
```
Example runs should then appear in the `build` directory. Each example also makes use of .yaml files to load parameters.

## Simple SE(2) Example:

The data for Figure 5.1 can be generated by running the following command:
```bash
build/SimpleInterpExample 1 simple_traj/BubblingParams.yaml
```
This will generate `simple_ex_...csv` files in the `build` directory, which can then be plotted using the `interp_plots.py` script.

## Giant Glass of Milk Figures:

The subefigures in Figure 5.3 were generated by running the Giant Glass of Milk example in `gtsam-examples' (see that directory for build/run instructions) with different parameters. The plots can be generated using the `plot_milk_results.py` script in the `python` directory. Note that the output `milk.csv` file from the Examples folder needs to be moved into the results directory of the Analysis folder for the python script to work.

## Lost in the Woods Figures:

All data for figures was generated using the `LostInTheWoods/LostInTheWoodsStudy.cpp` file with different parameter inputs. Then, the corresponding Python script (found in `python` subdirectory) can be used to generate the plots in the figures. The table below shows the mapping between figures, parameter files, and python scripts.

| Figure | YAML File | Python Script |
|--------|-----------| -----------------|
| Figure 5.5 | `configs/fig2_params.yaml` | `litw_fig2.py` |
| Figure 5.6 (Full Solve)| `configs/fig3_full_params.yaml` | `litw_fig3.py` |
| Figure 5.6 (Interpolated Solve)| `configs/fig3_params.yaml` | `litw_fig3.py` |
| Figure 4 | `configs/fig4_params.yaml` | `litw_fig4.py` |

## Lost in the Woods Analysis:

The quantitative timing analysis for the Lost in the Woods example (Figure 5.7) can be generated by running the `LostInTheWoods/WoodsTiming.cpp` file with different parameter inputs. The corresponding YAML files are found in the `configs` subdirectory, and the resulting data can be plotted using the `litw_timing.py` script in the `python` directory.

## Starry Night Example:

To regenerate Figure 5.11 and the subplots of 5.12, run the Starry night example in `gtsam-examples` with the odometry, WNOA and interpolation config files as follows:
```bash
build/StarryNight --config-file StarryNight/configs/starryNightOdom \
build/StarryNight --config-file StarryNight/configs/starryNightWNOA \
build/StarryNight --config-file StarryNight/configs/starryNightInterp \
```
These will generate the csv files need to generate the plots. Then, the plots can be generated using the `starryNight.py` script in the `gtsam-examples/StarryNight` directory.
